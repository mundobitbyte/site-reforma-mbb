10 — Visão Moderna de Dados

Outra tecnologia precisa resolver outro limite, não apenas trocar o nome do banco.

O que é necessário agora?

Glossário opcional em linguagem simples

Documentos agrupam campos; chave-valor associa um identificador a um valor; grafos representam nós e ligações; colunas amplas organizam famílias de colunas. OLTP trata operações; analytics estuda padrões. Warehouse organiza dados para análise; lake guarda dados de formatos variados; lakehouse combina recursos dessas abordagens. Embedding é representação numérica; busca vetorial procura proximidade; RAG recupera fontes antes de gerar uma resposta. Aqui são referências, não recursos implementados.

O que ainda justifica o relacional?

Pedido, item, preço e saldo têm relações e operações que precisam concordar. O relacional continua adequado ao piloto. JSON de uma API é um formato de mensagem; receber JSON não obriga guardar tudo num banco de documentos.

Famílias NoSQL incluem documentos, chave-valor, grafos e colunas amplas. Elas não eliminam modelagem. Compare conforme acesso, vínculos, integridade e operação; não acrescente infraestrutura ao piloto sem uma pergunta que ela resolva.

Escala e recuperação não são a mesma promessa

Escala vertical aumenta recursos de uma máquina; horizontal distribui trabalho. Réplica copia dados para outra instância; particionamento divide dados; cache reutiliza resultados. Uma réplica pode replicar uma exclusão: não a trate como substituto automático de backup.

Cloud gerenciada não dispensa decisão sobre acesso, retenção, custo e recuperação. Consistência distribuída precisa de condições concretas; o slogan “escolha dois” não resolve sozinho o projeto. A Cantina local não demonstrou escala distribuída.

Perguntas de análise e de IA

OLTP cuida de operações, como vender; analytics procura padrões. Warehouse, lake e lakehouse organizam usos analíticos diferentes; não são fases obrigatórias de qualquer sistema pequeno.

Embeddings, busca vetorial e RAG são aprofundamentos para busca e geração com fontes. Eles não substituem a conta exata do desconto. Dados de qualidade, origem e acesso continuam necessários em qualquer tecnologia. Use a visão moderna para decidir o que não precisamos implementar agora.

Separe fundamento de aprofundamento

O piloto precisa de relações, integridade, consultas e recuperação. Não precisa de um banco novo para cada conceito moderno. JSON é um formato de texto para trocar campos/valores; não determina onde guardar os dados. Use a tabela abaixo para decidir o que estudar depois.

Ver exemplo didático — não é evidência do aluno

Decisão didática: manter SQLite local para o laboratório de pedido/estoque; motivo dados relacionados e necessidade de reversão; limite não foi avaliada carga real nem disponibilidade distribuída. Migrar exigiria medir necessidades e comparar alternativas. Não é uma decisão validada para uma cantina em produção.

Faça e confira: Registre uma decisão proporcional, um limite e a evidência que buscaria antes de mudar arquitetura. Não há instalação, código, conta em nuvem ou resultado SQL obrigatório em BD10; termos avançados ficam como consulta opcional.
