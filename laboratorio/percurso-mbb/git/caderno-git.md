# Caderno Git da mesma Cantina
GIT00–GIT09. Não recrie Café Aurora ou a feira para repetir os fundamentos.
Para cada etapa: necessidade/RF, estado antes, hipótese, comando, estado depois, arquivo/índice/HEAD, commit e limite da evidência.
Diferencie retirar do índice, descartar edição, reverter commit e consultar outra versão.
Na revisão: problema → comportamento final → mudança → validação → pendências.
Na colaboração: origem, branch, versão comparada e resolução do conflito pelo RF aprovado.
Nenhum comando do roteiro usa GitHub. O remoto é bare local temporário.
Transferência remota real precisa conferir destino e permissões existentes, sem ampliar acesso ou selecionar All repositories.
