Experimentar a aplicação local

Use a cópia do repositório experimental. Este roteiro presume Python instalado e terminal na raiz do laboratório. Para a avaliação, o iniciador integrado cria um banco temporário com dados fictícios e serve aplicação e percurso juntos.

Instruções e limites da aplicação

Entre na pasta do serviço a partir da raiz do laboratório.

cd laboratorio/cantina-evolutiva

Crie um ambiente próprio.

python -m venv .venv

Ative no CMD do Windows.

.venv\Scripts\activate

Ou ative no Linux/macOS.

source .venv/bin/activate

Instale as dependências no ambiente ativado.

python -m pip install -r requirements.txt

Inicie o serviço local.

python previa_local.py

Abra http://127.0.0.1:8001/ no mesmo computador. Este endereço só funciona depois de iniciar o serviço; não é uma prévia hospedada.

Recarregar a página preserva os dados durante a sessão. Ctrl+C encerra e descarta o banco temporário; uma nova execução começa outro ensaio. O checkpoint 21 confirmou 360/320 px, teclado e foco; Narrador real confirmado pelo professor no checkpoint 27; primeira sessão com participante revelou dificuldades; nova observação dos pontos corrigidos continua pendente.
