Experimentar a aplicação local

Use a cópia do repositório experimental. Este roteiro presume Python instalado e terminal na raiz do laboratório. O serviço tem banco próprio com dados fictícios. Não aponte para banco da v1 ou de outro projeto.

Instruções e limites da aplicação

Entre na pasta do serviço a partir da raiz do laboratório.

cd laboratorio/cantina-evolutiva

Crie um ambiente próprio.

python -m venv .venv

Ative no CMD do Windows.

.venv\Scripts\activate

Ou ative no Linux/macOS.

source .venv/bin/activate

Instale as dependências no ambiente ativado.

python -m pip install -r requirements.txt

Inicie o serviço local.

python -m uvicorn app:app --host 127.0.0.1 --port 8001

Abra http://127.0.0.1:8001/ no mesmo computador. Este endereço só funciona depois de iniciar o serviço; não é uma prévia hospedada.

Registrar e consultar usam dados salvos; reiniciar mantém o banco. O uso real a 360 px e a compreensão das mensagens ainda precisam ser verificados.
