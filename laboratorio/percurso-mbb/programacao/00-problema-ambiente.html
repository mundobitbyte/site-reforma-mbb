A anotação de duas águas precisa virar uma resposta repetível, sem inventar uma segunda Cantina.

Antes de programar

A anotação de duas águas precisa virar uma resposta repetível, sem inventar uma segunda Cantina.

Pré-requisitos: Nenhuma experiência de programação. Use o caso fictício; o dossiê é uma referência, não uma etapa obrigatória anterior.

Conceitos que resolvem esta necessidade

algoritmo, arquivo .py, interpretador, terminal.

Abra o dossiê: RF-03 limita a quantidade; RF-06 define o valor; RF-08 exige gravação conjunta. Nesta primeira experiência resolveremos apenas o cálculo.

Algoritmo é uma sequência de passos para a tarefa. Escreva: conhecer preço e quantidade → multiplicar → mostrar subtotal. Desenhe entrada, cálculo e saída; não acrescente cupom ou estoque antes de explicar o cálculo.

O editor salva um arquivo; o interpretador Python executa esse arquivo; o terminal recebe o comando e mostra a resposta. Use Python 3.10 ou superior disponível no computador. A execução desta adaptação foi verificada em Python 3.12; os exemplos introdutórios usam apenas a biblioteca padrão.

  1. Na cópia experimental, abra a pasta laboratorio/percurso-mbb/programacao/exemplos no editor.
  2. Abra o terminal nessa pasta e confirme o interpretador.
  3. Abra 01_sequencia.py, leia o código e faça a previsão antes de executar.

Se python não existir no Windows, confirme py --version e use py nos comandos. Instalação e seleção do interpretador estão no acervo Python; nenhum número de versão do computador do aluno é presumido.

Comece e confira

O site mostra o material; os programas Python são executados no computador. No celular você pode ler e prever, mas estes comandos exigem um computador com Python. Você não precisa iniciar a API nem instalar pacotes nas etapas 0–11.

  1. Abra o repositório experimental na branch publicada. Use Code → Download ZIP e extraia o ZIP; não execute dentro do arquivo compactado. Se já tem a cópia atual, aproveite-a.
  2. Dentro da pasta extraída, abra laboratorio → percurso-mbb → programacao → exemplos. Confirme que estão juntos 01_sequencia.py e regras.py.
  3. No Windows, nessa pasta do Explorador, digite cmd na barra de endereço e pressione Enter. Abre o CMD na pasta correta; estes passos não usam PowerShell. Em Linux/macOS, abra o terminal nessa pasta.
  4. Confira Python com o comando apropriado abaixo. Se não existir, instale pela página oficial do Python, reabra o terminal e confira novamente. Se python não funcionar, use py no Windows ou python3 em Linux/macOS nos comandos desta fase.
  5. Abra 01_sequencia.py num editor de texto/código. Só leia primeiro; mantenha extensão .py, não .py.txt. Não copie vários programas num mesmo arquivo.

Previsão: preço 300 × quantidade 2 = 600. Isso é um cálculo da simulação, não uma venda salva. No PG00 registre entrada, cálculo, saída e o comando que seu computador realmente executou.

Windows: conferir interpretador

py --version

Linux/macOS: conferir interpretador

python3 --version

Na pasta exemplos: executar o primeiro programa

python 01_sequencia.py

Pressione Enter após o comando. Devem aparecer duas linhas: Água e Subtotal em centavos: 600. O terminal volta a aceitar comandos. Se surgir >>>, você abriu o interpretador interativo: digite exit() e rode o comando no terminal. “Não foi possível abrir arquivo” pede conferir pasta/nome, não alterar o código. Registre sua saída e data em PG00.
