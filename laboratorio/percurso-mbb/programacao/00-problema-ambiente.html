0 — Problema, algoritmo e ambiente

A anotação de duas águas precisa virar uma resposta repetível, sem inventar uma segunda Cantina.

Antes de programar

A anotação de duas águas precisa virar uma resposta repetível, sem inventar uma segunda Cantina.

Pré-requisitos: Caso fictício e dossiê de Análise.

Conceitos que resolvem esta necessidade

algoritmo, arquivo .py, interpretador, terminal.

Abra o dossiê: RF-03 limita a quantidade; RF-06 define o valor; RF-08 exige gravação conjunta. Nesta primeira experiência resolveremos apenas o cálculo.

Algoritmo é uma sequência de passos para a tarefa. Escreva: conhecer preço e quantidade → multiplicar → mostrar subtotal. Desenhe entrada, cálculo e saída; não acrescente cupom ou estoque antes de explicar o cálculo.

O editor salva um arquivo; o interpretador Python executa esse arquivo; o terminal recebe o comando e mostra a resposta. Use a instalação de Python disponível no laboratório. A execução desta adaptação foi verificada em Python 3.12; os exemplos introdutórios usam apenas a biblioteca padrão.

  1. Na cópia experimental, abra a pasta laboratorio/percurso-mbb/programacao/exemplos no editor.
  2. Abra o terminal nessa pasta e confirme o interpretador.
  3. Abra 01_sequencia.py, leia o código e faça a previsão antes de executar.

Se python não existir no Windows, confirme py --version e use py nos comandos. Instalação e seleção do interpretador estão no acervo Python; nenhum número de versão do computador do aluno é presumido.

Prática com código completo

python --version

Preveja, execute e compare
