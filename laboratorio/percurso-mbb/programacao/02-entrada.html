2 — Entrada, conversão e apresentação

O atendente precisa informar a quantidade em vez de editar o programa a cada pedido.

Antes de programar

O atendente precisa informar a quantidade em vez de editar o programa a cada pedido.

Pré-requisitos: Etapas 0–1.

Conceitos que resolvem esta necessidade

input, int, f-string, divisão inteira, resto, formatação.

input devolve texto. int(texto) tenta convertê-lo em inteiro. Nesta etapa use uma entrada inteira conhecida: 2. int("duas") falha; vamos tratar essa falha na etapa 8, depois de compreender decisão, repetição e função.

Uma f-string começa com f e coloca expressões entre chaves. Para um subtotal não negativo, // 100 fornece reais inteiros e % 100 fornece os centavos restantes; :02d exibe pelo menos dois dígitos. A conta permanece em centavos inteiros.

Compare o mesmo cálculo com VisuAlg. A escrita muda; dados e operação continuam os mesmos. Um texto exibido não é comprovante de venda salva.

Prática com código completo

02_entrada.py

preco_centavos = 300
texto = input("Quantidade de águas: ")
quantidade = int(texto)
subtotal_centavos = preco_centavos * quantidade
print(f"Subtotal: R$ {subtotal_centavos // 100},{subtotal_centavos % 100:02d}")

Abrir arquivo 02_entrada.py. Execute na pasta exemplos com python 02_entrada.py.

Preveja, execute e compare

Com entrada 2: Subtotal: R$ 6,00. Com 3: R$ 9,00. Não aceitar saída prevista como execução.

Use 2 e 3. Guarde letras como caso previsto para retomar na etapa 8.
