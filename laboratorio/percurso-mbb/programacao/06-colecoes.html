6 — Lista de itens e campos com nome

Um pedido pode ter Água, Suco e Salgado, sem variáveis numeradas para cada posição.

Antes de programar

Um pedido pode ter Água, Suco e Salgado, sem variáveis numeradas para cada posição.

Pré-requisitos: Etapas 0–5.

Conceitos que resolvem esta necessidade

lista, dicionário, chave, índice, get, coleções aninhadas.

Uma lista guarda uma sequência de itens; um dicionário relaciona chave e valor. produtos[1] busca por identificador, e item["quantidade"] busca um campo pelo nome. Uma lista de dicionários descreve várias linhas com a mesma estrutura.

Na lista, itens[0] acessa o primeiro item: a posição começa em zero. No dicionário, produtos[1] procura a chave 1, que é o identificador do produto. Posição e identificador têm funções diferentes.

get(chave, 0) lê o valor existente ou devolve 0 quando não há essa chave. Assim acumulamos a quantidade por produto. Nos dados conhecidos, 2 Águas + 2 Salgados + 2 Sucos somam 3400 centavos.

O mini-cardápio é um recorte do mesmo cadastro para observar coleções, não uma nova fonte de preços para vendas. A consulta definitiva usa o serviço. ID inexistente, quantidade excessiva e mutação de listas ainda não são tratados neste recorte.

Uma lista em memória não é uma tabela persistida. Compare campos com o modelo lógico; o item salvo guarda o preço da venda.

Prática com código completo

06_colecoes.py

produtos = {
    1: {"nome": "Água", "preco_centavos": 300},
    2: {"nome": "Suco", "preco_centavos": 600},
    3: {"nome": "Salgado", "preco_centavos": 800},
}
itens = [
    {"produto_id": 1, "quantidade": 2},
    {"produto_id": 3, "quantidade": 2},
    {"produto_id": 2, "quantidade": 2},
]
subtotal_centavos = 0
quantidades = {}
for item in itens:
    produto_id = item["produto_id"]
    quantidade = item["quantidade"]
    produto = produtos[produto_id]
    quantidades[produto_id] = quantidades.get(produto_id, 0) + quantidade
    subtotal_centavos = subtotal_centavos + produto["preco_centavos"] * quantidade
    print(produto["nome"], quantidade)
print("Quantidades:", quantidades)
print("Subtotal em centavos:", subtotal_centavos)

Abrir arquivo 06_colecoes.py. Execute na pasta exemplos com python 06_colecoes.py.

Preveja, execute e compare
