7 — Nomear uma responsabilidade

O cálculo de subtotal reaparece; a interface e o teste precisam usar a mesma regra.

Antes de programar

O cálculo de subtotal reaparece; a interface e o teste precisam usar a mesma regra.

Pré-requisitos: Etapas 0–6.

Conceitos que resolvem esta necessidade

def, parâmetro, argumento, return, escopo local.

def define a função; a chamada envia argumentos para os parâmetros; return devolve o resultado. O corpo só executa quando a função é chamada. As variáveis criadas dentro dela são locais à chamada.

Separe cálculo de apresentação. subtotal_item recebe números e devolve um número, sem pedir entrada, imprimir, gravar arquivo ou alterar estoque. O chamador acumula e exibe.

Sem return explícito em um caminho, o resultado é None. Este exemplo pressupõe preço conhecido e quantidade válida; a função será revisitada para acrescentar a validação na próxima etapa.

Prática com código completo

07_funcoes.py

def subtotal_item(preco_centavos, quantidade):
    return preco_centavos * quantidade


total = 0
for item in [
    {"preco_centavos": 300, "quantidade": 2},
    {"preco_centavos": 800, "quantidade": 2},
]:
    total = total + subtotal_item(item["preco_centavos"], item["quantidade"])
print("Subtotal em centavos:", total)

Abrir arquivo 07_funcoes.py. Execute na pasta exemplos com python 07_funcoes.py.
