9 — Reutilizar o código entre arquivos

Uma regra copiada em cada tela pode divergir; um módulo permite compartilhar uma definição.

Antes de programar

Uma regra copiada em cada tela pode divergir; um módulo permite compartilhar uma definição.

Pré-requisitos: Etapas 0–8.

Conceitos que resolvem esta necessidade

import, módulo, main, __name__, biblioteca padrão.

Um arquivo Python pode ser um módulo. from regras import subtotal_item disponibiliza a função do arquivo regras.py na mesma pasta. A regra de quantidade é a revisão do exercício anterior; preço continua conhecido e a função não é o serviço completo.

main é um nome escolhido para organizar a entrada. Quando o arquivo é executado diretamente, __name__ vale "__main__"; o bloco chama a função. Ao importar esse módulo, o bloco não dispara a demonstração.

Não renomeie arquivos próprios para json.py, sqlite3.py ou nomes de bibliotecas que serão importadas. O programa poderia carregar o arquivo local errado. Biblioteca padrão vem com Python; pacote externo é instalado no ambiente; framework organiza partes da aplicação. Essas palavras não são sinônimos.

Comece e confira

Importar é procurar uma definição em outro arquivo, não copiar sua função para o chamador. Confira no editor, na mesma pasta:

  • regras.py: define validação e cálculo.
  • 09_modulos.py: importa e chama o cálculo; apresenta a saída.
  • 10_arquivo_json.py e 13_testes.py: também reutilizam regras.py nas próximas etapas.
Ver exemplo didático — não é evidência do aluno

from regras import subtotal_item encontra regras.py, disponibiliza a função e só a executa quando chamada. Executar 09_modulos.py mostra 2200; importar esse módulo não dispara main().

Execute o exemplo. Se surgir ModuleNotFoundError: regras, confira nome regras.py e pasta conjunta; não instale um pacote chamado regras. No PG09 desenhe chamador → módulo → função e indique onde a validação foi definida.

Prática com código completo

regras.py

"""Regras de exercício: não substituem as validações do serviço Cantina."""


def validar_quantidade(quantidade):
    if type(quantidade) is not int or quantidade < 1 or quantidade > 10:
        raise ValueError("Use um inteiro de 1 a 10; booleano não é quantidade.")
    return quantidade


def subtotal_item(preco_centavos, quantidade):
    validar_quantidade(quantidade)
    return preco_centavos * quantidade

Abrir arquivo regras.py. Mantenha esse arquivo na mesma pasta de 09_modulos.py. Ele fornece as funções importadas; não precisa ser executado separadamente e não mostra uma saída própria.

09_modulos.py

from regras import subtotal_item


def main():
    total = subtotal_item(300, 2) + subtotal_item(800, 2)
    print("Subtotal em centavos:", total)


if __name__ == "__main__":
    main()

Abrir arquivo 09_modulos.py. Execute na pasta exemplos com python 09_modulos.py.

Preveja, execute e compare

2200 centavos. Importar regras não pede entrada nem imprime saída.

Localize a definição usada pelo chamador e explique onde corrigir a regra.
