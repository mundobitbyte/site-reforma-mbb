13 — Transformar exemplos em evidências repetíveis

“Funcionou com 2” não diz o que acontece com 0, 11, True ou uma falha de gravação.

Antes de programar

“Funcionou com 2” não diz o que acontece com 0, 11, True ou uma falha de gravação.

Pré-requisitos: Etapas 0–12.

Conceitos que resolvem esta necessidade

unittest, Arrange–Act–Assert, assertEqual, assertRaises, subTest, pytest, breakpoint.

Prepare uma entrada, execute a operação e compare com um resultado previsto pela regra: Arrange–Act–Assert. O número esperado vem do preço conhecido e da quantidade, não de recalcular a mesma função dentro da expectativa.

unittest é biblioteca padrão. Métodos cujo nome começa por test_ são executados pelo runner; assertEqual compara, assertRaises espera o erro e subTest identifica cada valor numa lista de casos. Este arquivo verifica a pequena regra de exercício; não mede cobertura total da aplicação.

Para o projeto, pytest executa os testes de pedido, cupom, estados, prática de BD e terminal. Os bancos de teste são temporários. O checkpoint 21 exercitou a interface em Chromium real integrado à API/serviço/SQLite temporário; leitor de tela real e compreensão por estudantes continuam pendentes. python -m pytest usa o interpretador do ambiente ativado.

Na depuração, coloque um breakpoint na atualização do acumulador, antes de alterar a linha. Observe valores e avance um passo. Compare com o teste de mesa de PG05. Não há sessão do depurador ou avaliação com estudantes registrada como executada nesta adaptação.

Prática com código completo

13_testes.py

import unittest

from regras import subtotal_item, validar_quantidade


class TestRegras(unittest.TestCase):
    def test_limites_inclusivos(self):
        self.assertEqual(validar_quantidade(1), 1)
        self.assertEqual(validar_quantidade(10), 10)

    def test_quantidades_recusadas(self):
        for quantidade in [0, -1, 11, 1.5, True, "2"]:
            with self.subTest(quantidade=quantidade):
                with self.assertRaises(ValueError):
                    validar_quantidade(quantidade)

    def test_preco_conhecido_e_quantidade(self):
        self.assertEqual(subtotal_item(300, 2), 600)
        self.assertEqual(subtotal_item(800, 2), 1600)


if __name__ == "__main__":
    unittest.main()
