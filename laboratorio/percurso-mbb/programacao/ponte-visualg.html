Sequencia

Entrada 2 → subtotal 600 centavos. Python também formata R$ 6,00; comparar valor não exige textos idênticos.

02_sequencia.alg

algoritmo "Cantina_Sequencia"
var
   quantidade, precoCentavos, subtotalCentavos: inteiro
inicio
   precoCentavos <- 300
   escreva("Quantidade de aguas: ")
   leia(quantidade)
   subtotalCentavos <- precoCentavos * quantidade
   escreval("Subtotal em centavos: ", subtotalCentavos)

Decisao

Entradas 0/11 são recusadas; 1/10 passam com saldo 20. Para observar falta de estoque, use saldo 1 e quantidade 2 nas duas simulações.

03_decisao.alg

algoritmo "Cantina_Decisao"
var
   quantidade, estoque, subtotalCentavos: inteiro
inicio
   estoque <- 20
   escreva("Quantidade de aguas: ")
   leia(quantidade)
   se (quantidade < 1) ou (quantidade > 10) entao
      escreval("Quantidade recusada: use de 1 a 10.")
   senao
      se quantidade > estoque entao
         escreval("Estoque insuficiente.")
      senao
         subtotalCentavos <- 300 * quantidade
         escreval("Simulacao aceita em centavos: ", subtotalCentavos)
      fimse
   fimse
fimalgoritmo

Arquivo VisuAlg

03_decisao.py

preco_centavos = 300
estoque = 20
quantidade = int(input("Quantidade de águas: "))
if quantidade < 1 or quantidade > 10:
    print("Quantidade recusada: use um inteiro de 1 a 10.")
elif quantidade > estoque:
    print("Estoque insuficiente.")
else:
    subtotal_centavos = preco_centavos * quantidade
    print(f"Simulação aceita: {subtotal_centavos} centavos.")

Repeticao

Sequência 0, 11, 2: duas recusas e subtotal 600. Entrada não numérica continua como limite a tratar na etapa 8 de Python.

04_repeticao.alg

algoritmo "Cantina_Repeticao"
var
   quantidade, subtotalCentavos: inteiro
inicio
   quantidade <- 0
   enquanto (quantidade < 1) ou (quantidade > 10) faca
      escreva("Quantidade de aguas (1 a 10): ")
      leia(quantidade)
      se (quantidade < 1) ou (quantidade > 10) entao
         escreval("Tente novamente com um inteiro de 1 a 10.")
      fimse
   fimenquanto
   subtotalCentavos <- 300 * quantidade
   escreval("Subtotal em centavos: ", subtotalCentavos)

Arquivo VisuAlg

04_repeticao.py

quantidade = 0
while quantidade < 1 or quantidade > 10:
    quantidade = int(input("Quantidade de águas (1 a 10): "))
    if quantidade < 1 or quantidade > 10:
        print("Tente novamente com um inteiro de 1 a 10.")
subtotal_centavos = 300 * quantidade
print("Subtotal em centavos:", subtotal_centavos)
