13 — Resposta e banco precisam concordar

Uma recusa que altera saldo continua defeituosa.

Necessidade e pré-requisito

Uma recusa que altera saldo continua defeituosa.

Pré-requisito: QTS12; WEB06/WEB08; BD07

Para aprofundar, consulte o acervo preservado: Resposta e banco precisam concordar. Esta ponte acrescenta os artefatos da evolução.

Aplicar à mesma Cantina

Contrato HTTP e efeito transacional observado.

Use Q-06/Q-08; compare todas as tabelas antes/depois da recusa na evolução. Retome o roteiro HTTP temporário de Web/API.

Critérios da versão evolutiva · Casos e resultados · Arquivos executáveis e código completo

python laboratorio/percurso-mbb/qts/exemplos/comparar_versoes.py

Na raiz do repositório experimental, com o ambiente Python da Cantina ativado. Não altera bancos de trabalho.

Como executar e conferir

Prepare o ambiente em WEB06. Na raiz extraída:

.venv-web\Scripts\python.exe laboratorio\percurso-mbb\qts\exemplos\recusa_http_banco.py

A saída mostra HTTP 400 e todas as tabelas antes/depois: cupom abaixo do mínimo, nenhum novo pedido/item/evento, estoque e disponibilidade do cupom preservados. Compare os dados, não só o status. O script usa um banco temporário novo e o descarta ao terminar.

Código completo do diagnóstico isolado
"""Observa uma recusa em banco temporário; nunca abre banco de trabalho."""
import json
import tempfile
from comparar_versoes import ambiente, snapshot

with tempfile.TemporaryDirectory(prefix='mbb-recusa-') as pasta:
    with ambiente('evolucao', pasta) as (client, banco):
        antes = snapshot(banco)
        resposta = client.post('/api/pedidos', json={
            'itens': [{'produto_id': 1, 'quantidade': 2}], 'cupom': 'MBB10'})
        depois = snapshot(banco)
        print(json.dumps({'http': resposta.status_code, 'resposta': resposta.json(),
                          'antes': antes, 'depois': depois,
                          'banco_preservado': antes == depois},
                         ensure_ascii=False, indent=2))
        assert resposta.status_code == 400
        assert antes == depois
