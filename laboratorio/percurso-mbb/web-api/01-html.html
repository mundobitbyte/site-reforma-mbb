1 — Estruturar antes de estilizar

A página precisa dizer onde a pessoa está e o que pode consultar, antes de receber cores e comportamento.

Antes de construir

A página precisa dizer onde a pessoa está e o que pode consultar, antes de receber cores e comportamento.

Pré-requisitos: WEB00.

Conceitos por necessidade

elemento, atributo, hierarquia, header, main, section, article, h1, caminho relativo.

Um elemento tem finalidade; atributos descrevem informações ou relações. h1 identifica a página; h2 organiza seções e h3 o produto. main contém o conteúdo principal. O atributo lang="pt-BR" indica o idioma.

Crie a estrutura com o produto Água já conhecido do modelo, sem inventar cadastro de cliente, pagamento ou fornecedor. aria-labelledby liga a seção ao título por ID. Isso é marcação prevista; sua interpretação por tecnologia assistiva ainda precisa de teste.

Abra o arquivo desta etapa no navegador do seu computador. Ele não faz rede nem consulta o estoque. Não interprete o preço escrito na página como o preço confirmado de uma venda.

Prática com arquivos completos

01-estrutura/index.html

<!doctype html>
<html lang="pt-BR">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width,initial-scale=1">
  <title>Cantina Horizonte — estrutura de estudo</title>
</head>
<body>
  <header><h1>Cantina Horizonte</h1><p>Escola Horizonte — dados fictícios.</p></header>
  <main>
    <section aria-labelledby="cardapio-titulo">
      <h2 id="cardapio-titulo">Um produto do cardápio</h2>
      <article><h3>Água</h3><p>Preço de referência: R$ 3,00.</p></article>
      <p>Este recorte não consulta estoque nem registra venda.</p>
    </section>
  </main>
</body>
</html>

Abrir 01-estrutura/index.html.

Como executar e conferir

Na cópia extraída, abra laboratorio/percurso-mbb/web-api/exemplos/01-estrutura. Arquivos dessa atividade: index.html. Preserve os nomes e mantenha os arquivos juntos. Antes de alterar, faça uma cópia dessa pasta para seu exercício.

Abra os arquivos num editor de texto. Para criar um arquivo, cole o código completo, salve em UTF-8 com o nome indicado e escolha “Todos os arquivos” se o editor oferecer essa opção; confira que não virou .html.txt. Salve com Ctrl+S. Abra index.html no navegador e recarregue após editar.

Estas páginas estáticas podem abrir diretamente como arquivo local. Não registram vendas nem consultam a API. A atividade de API a partir de WEB06 exige servidor HTTP. Aqui a evidência é o que aparece e funciona na página; não invente um código HTTP.

Preveja, experimente e compare

Identifique início/fim dos elementos e confirme uma única função para cada título.

Registre o que espera antes de executar. Acrescente resultado real, diferença e limite depois; as verificações de código desta adaptação não são teste visual ou sessão com aluno.
