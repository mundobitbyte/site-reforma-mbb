3 — Apresentação, caixa e adaptação ao espaço

O campo e a resposta precisam continuar legíveis em uma largura pequena.

Antes de construir

O campo e a resposta precisam continuar legíveis em uma largura pequena.

Pré-requisitos: WEB00–WEB02.

Conceitos por necessidade

seletor, regra CSS, modelo de caixa, grid, unidade relativa, media query, foco visível.

Um seletor escolhe os elementos; uma regra define propriedades e valores. box-sizing: border-box faz a largura declarada incluir borda e preenchimento. rem relaciona medidas ao tamanho de fonte raiz. A largura com min e calc respeita um limite e deixa margem.

display: grid organiza os campos com espaçamento. O foco visível ajuda a localizar o controle pelo teclado. A media query altera uma regra a partir de uma largura; não prova que o layout funciona em todos os dispositivos.

O formulário continua sem comportamento até WEB04. A identidade deste recorte usa cores e tipografia do laboratório da Cantina. No aplicativo completo, Grid organiza produtos e carrinho e se reduz para uma coluna em espaço menor.

Teste a 360 px, com texto ampliado e teclado, quando houver navegador disponível. Nada disso foi declarado executado aqui; a inspeção do CSS não substitui a observação.

03-estilo/index.html

<!doctype html>
<html lang="pt-BR">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width,initial-scale=1">
  <title>Cantina Horizonte — formulário de estudo</title>
  <link rel="stylesheet" href="styles.css">
</head>
<body>
  <header><h1>Cantina Horizonte</h1><p>Simulação com Água a R$ 3,00.</p></header>
  <main>
    <section aria-labelledby="simulacao-titulo">
      <h2 id="simulacao-titulo">Quantidade de águas</h2>
      <form id="simulacao">
        <label for="quantidade">Quantidade (1 a 10)</label>
        <input id="quantidade" type="number" min="1" max="10" step="1" required value="2">
        <button type="submit" disabled>Calcular simulação</button>
      </form>
      <p id="resultado" role="status" aria-live="polite">O botão será habilitado no estudo de JavaScript. Nenhuma venda é registrada.</p>
    </section>
  </main>
</body>
</html>

03-estilo/styles.css

* { box-sizing: border-box; }
body { margin: 0; font-family: system-ui, sans-serif; line-height: 1.5; color: #172033; background: #f5f7fb; }
header, main { width: min(60rem, calc(100% - 2rem)); margin: 1rem auto; }
section { padding: 1rem; background: white; border: 1px solid #cfd7e5; border-radius: .75rem; }
form { display: grid; gap: .6rem; max-width: 24rem; }
button, input { font: inherit; padding: .75rem; border-radius: .4rem; }
input { min-width: 0; width: 100%; border: 1px solid #6a7489; }
button { border: 0; background: #2457d6; color: white; cursor: pointer; }
button:disabled { opacity: .65; cursor: default; }
button:focus-visible, input:focus-visible { outline: 3px solid #b45309; outline-offset: 3px; }
p { overflow-wrap: anywhere; }
@media (min-width: 48rem) { main { max-width: 45rem; } }
