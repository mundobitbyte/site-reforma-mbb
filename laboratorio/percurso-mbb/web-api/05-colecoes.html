5 — O carrinho representa vários itens

Vários produtos precisam seguir juntos para o servidor, sem enviar preço como autoridade.

Antes de construir

Vários produtos precisam seguir juntos para o servidor, sem enviar preço como autoridade.

Pré-requisitos: WEB00–WEB04; PG06/PG07.

Conceitos por necessidade

array, objeto, for of, let, map, arrow function, JSON.stringify, campo do objeto, console.log, null.

Um array é uma sequência; um objeto guarda campos com nome. for...of percorre os itens. let permite reatribuir o acumulador. A multiplicação de quantidade por preço conhecido produz o subtotal previsto, como em PG06.

map transforma cada item em outro objeto; a arrow function recebe o item e devolve apenas produto_id/quantidade. Os parênteses ao redor do objeto indicam retorno da expressão. O preço usado para exibição fica fora do corpo enviado.

JSON.stringify serializa uma estrutura como texto JSON. Uma string JSON não é o objeto JavaScript em memória. No contrato, quantidade 2 é número; "2" é texto. O servidor estrito recusa texto/booleano como quantidade.

item.quantidade lê o campo do objeto, assim como item["quantidade"] no dicionário do exemplo Python. console.log mostra a previsão no console; não altera a página. Em cupom: null, null indica ausência de cupom. Não é o texto "null"; o JSON conserva essa diferença.

O recorte só prepara a entrada: subtotal 2200 e duas linhas. A interface completa consolida repetição no carrinho e o serviço valida cada linha e a soma. Este array não foi vendido.

Prática com arquivos completos

05-colecoes.mjs

const itens = [
  { produto_id: 1, quantidade: 2, preco_centavos: 300 },
  { produto_id: 3, quantidade: 2, preco_centavos: 800 },
];
let subtotal_centavos = 0;
for (const item of itens) {
  subtotal_centavos = subtotal_centavos + item.quantidade * item.preco_centavos;
}
console.log("Subtotal previsto em centavos:", subtotal_centavos);
const entrada = itens.map(item => ({
  produto_id: item.produto_id,
  quantidade: item.quantidade,
}));
console.log(JSON.stringify({ itens: entrada, cupom: null }));

Abrir 05-colecoes.mjs.
