6 — Um contrato para perguntar e pedir alteração

Dois programas precisam concordar sobre rota, método, corpo e significado da resposta.

Antes de construir

Dois programas precisam concordar sobre rota, método, corpo e significado da resposta.

Pré-requisitos: WEB00–WEB05; PG12/BD09.

Conceitos por necessidade

HTTP, URL, rota, GET, POST, header, status, JSON, contrato.

A URL local contém esquema HTTP, host 127.0.0.1, porta 8001 e caminho. A rota indica o recurso; o método expressa a operação. GET consulta; POST de pedidos solicita uma nova venda. A resposta traz status e corpo; o corpo JSON contém os dados ou o motivo da recusa.

O header Content-Type: application/json descreve o formato do corpo enviado. Não confunda Content-Type com autenticação. Consultar um ID é diferente de registrar outra venda, mesmo quando o texto da tela parece semelhante.

Abra as quatro operações e os códigos realmente implementados. O exemplo de entrada é completo; a lista de campos de saída é um recorte relevante, não uma resposta completa inventada com datas.

Com a cópia experimental e o ambiente preparados, inicie o serviço. Abrir os HTML de estudo não o inicia; nem publicar HTML estático executa FastAPI. Use o endereço local no mesmo computador.

Prática com arquivos completos

Na pasta cantina-evolutiva, com ambiente ativado

python -m uvicorn app:app --host 127.0.0.1 --port 8001
Como executar e conferir

Use uma cópia extraída do ZIP experimental. Não trabalhe no site oficial. A raiz correta contém as pastas laboratorio, css e pages. Extraia o ZIP antes de abrir arquivos; não execute dentro do arquivo compactado.

No Windows, no Explorador, abra a raiz extraída, digite cmd na barra de endereço e pressione Enter. O terminal deve abrir nessa pasta. dir laboratorio\cantina-evolutiva\requirements.txt precisa encontrar o arquivo; se não encontrar, corrija a pasta antes de continuar. Os comandos abaixo usam o Prompt de Comando do Windows, um por vez.

Com Python 3.10 ou superior instalado, prepare um ambiente separado. Na raiz extraída:

py -3 --version
py -3 -m venv .venv-web
.venv-web\Scripts\python.exe -m pip install -r laboratorio\cantina-evolutiva\requirements.txt
.venv-web\Scripts\python.exe laboratorio\cantina-evolutiva\previa_local.py
Comandos para Linux/macOS
python3 --version
python3 -m venv .venv-web
.venv-web/bin/python -m pip install -r laboratorio/cantina-evolutiva/requirements.txt
.venv-web/bin/python laboratorio/cantina-evolutiva/previa_local.py

Deixe esse terminal aberto. Abra http://127.0.0.1:8001/: deve aparecer a Cantina. Esta prévia cria um banco temporário com data didática 07/10/2026. Recarregar preserva a sessão; Ctrl+C encerra e descarta o banco. A API normal pode usar banco persistente; não a utilize nesta prática. GitHub Pages apresenta materiais estáticos e não executa o serviço Python.

Se a porta estiver ocupada, encerre apenas sua prévia anterior ou use --port 8002 e adapte o endereço do cliente. Se faltar módulo, confira se executou o Python de .venv-web. Não atualize ou apague bancos existentes para resolver a preparação.

Preveja, experimente e compare

Descreva por que consultar pedido não deve baixar estoque nem registrar outro pedido.

Registre o que espera antes de executar. Acrescente resultado real, diferença e limite depois; as verificações de código desta adaptação não são teste visual ou sessão com aluno.
