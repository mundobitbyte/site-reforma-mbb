11 — Testar cada camada e declarar seu limite

Testar a função de rede não confirma que uma pessoa consegue registrar e entender a mensagem.

Antes de construir

Testar a função de rede não confirma que uma pessoa consegue registrar e entender a mensagem.

Pré-requisitos: WEB00–WEB10; PG13.

Conceitos por necessidade

teste de módulo, HTTP local, teste de servidor, observação humana, 360 px, Web Storage, documentação.

Os testes dos recortes JavaScript substituem Fetch por respostas controladas: verificam corpo, status, mensagem e ausência de reenvio. A prova HTTP local usa os módulos contra a API em banco temporário. A suíte Python verifica regras e persistência. Cada evidência responde a uma pergunta diferente.

O checkpoint 21 confirmou os fluxos principais em Chromium real, 360/320 px, teclado e foco. O 27 acrescentou as confirmações do Narrador pelo professor. A avaliação do laboratório foi encerrada nos checkpoints 41 e 43 (31/31), incluindo o retorno relatado com participante. Esse registro histórico não comprova automaticamente a autonomia de cada novo aluno ou cada revisão posterior. Resultados novos só entram no caderno depois da observação.

O Web I ensina localStorage/sessionStorage. A Cantina integrada mantém o carrinho em memória e os pedidos no servidor; não grava o carrinho no Web Storage. Armazenamento no navegador não é autoridade de preço/estoque, não é equivalente ao SQLite e não deve guardar credenciais para simular login inexistente.

Publicação estática não hospeda o serviço Python. Não há entrega em domínio oficial neste piloto. Documente instruções, dependências, ambiente e limites antes de escolher hospedagem compatível.

Prática com arquivos completos

Opcional, na pasta laboratorio/percurso-mbb/web-api, testar módulos com Node

node --test tests/clientes.test.mjs tests/simulacao.test.mjs

Opcional, na pasta laboratorio/percurso-mbb/web-api, com Python do ambiente da Cantina e Node

python tests/verificar_http_local.py

O roteiro cria banco temporário e encerra sua API ao terminar. Não aponte http-local.mjs para o banco de trabalho.

Na pasta laboratorio/cantina-evolutiva, com ambiente ativado, testar o servidor

python -m pytest -q tests

Preveja, experimente e compare

Separe o que a execução HTTP provou do que só a observação no navegador poderá provar.

Registre o que espera antes de executar. Acrescente resultado real, diferença e limite depois; as verificações de código desta adaptação não são teste visual ou sessão com aluno.
