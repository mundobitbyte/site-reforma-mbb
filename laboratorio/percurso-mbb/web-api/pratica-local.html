Prática HTTP local — uma operação por vez

Como executar e conferir

Primeiro conclua a preparação de WEB06. Instale e confira Node conforme WEB05. Num segundo terminal, abra a pasta laboratorio/percurso-mbb/web-api/exemplos. Os módulos 07–09 apenas exportam funções; executá-los sozinhos não envia requisição. O roteiro abaixo chama essas funções.

node pratica-api.mjs produtos
node pratica-api.mjs registrar

A consulta mostra o cardápio. Execute registrar uma única vez: em base nova, espere duas Águas, total 600 centavos, estado Novo. Anote o id realmente retornado. Nos comandos seguintes, substitua ID por esse número, sem escrever as letras ID:

node pratica-api.mjs consultar ID
node pratica-api.mjs avancar ID
node pratica-api.mjs conflito ID
node pratica-api.mjs consultar ID

Primeira consulta: Novo. Avanço: Confirmado. Conflito simula uma consulta antiga de Novo: espere HTTP 409, saída de erro, sem segundo avanço. A última consulta deve continuar Confirmado. O erro não exige novo registro. Se a conexão falhar, não há status HTTP recebido e o cliente não confirma o resultado: não repita POST automaticamente. Com ID conhecido, consulte; sem ID, confira a situação antes de qualquer nova tentativa.

Porta alternativa: o último argumento é a base; por exemplo node pratica-api.mjs consultar 1 http://127.0.0.1:8002. Para produtos/registrar, use um argumento auxiliar: node pratica-api.mjs produtos - http://127.0.0.1:8002.

Cliente completo — copiar para estudo
// Prática local: reutiliza os clientes existentes; nunca repete um POST.
import { consultarProdutos, consultarPedido } from './07-consulta.mjs';
import { registrarPedido } from './08-pedido.mjs';
import { avancarPedido } from './09-estados.mjs';
const [acao, argumento, base = 'http://127.0.0.1:8001'] = process.argv.slice(2);
try {
  let resultado;
  if (acao === 'produtos') resultado = await consultarProdutos(base);
  else if (acao === 'registrar') {
    resultado = await registrarPedido(base, [{ produto_id: 1, quantidade: 2 }]);
  } else if (['consultar', 'avancar', 'conflito'].includes(acao)) {
    const pedido = await consultarPedido(base, Number(argumento));
    if (acao === 'consultar') resultado = pedido;
    else if (acao === 'avancar') resultado = await avancarPedido(base, pedido);
    else {
      // Simula uma tela antiga, depois do primeiro avanço de Novo.
      if (pedido.status !== 'Confirmado') throw new Error('Execute conflito somente após Novo → Confirmado.');
      resultado = await avancarPedido(base, { ...pedido, status: 'Novo', proximo_status: 'Confirmado' });
    }
  } else throw new Error('Use produtos, registrar, consultar ID, avancar ID ou conflito ID.');
  console.log(JSON.stringify(resultado, null, 2));
} catch (erro) {
  console.error(erro.status ? `HTTP ${erro.status}: ${erro.message}` : erro.message);
  process.exitCode = 1;
}
